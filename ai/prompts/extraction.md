# Extraction prompt starter
Follow this project's protocol and extraction/codebook.md. Extract only the specified
fields from the supplied report. For each candidate include study_id, report_id,
arm, outcome, timepoint, field, value, value_status, unit, and exact source_location.
Add a brief supporting quote when useful. Preserve reported values and units.
Record missing or ambiguous values explicitly. Do not infer unavailable numeric data.
Save the candidates under ai/runs/ with status pending for human verification.
