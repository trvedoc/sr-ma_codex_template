# AI proposals and run history
Create one folder under runs/ per use, named with a date and stable run ID.
Copy run-metadata.example.json, fill it, and save prompt.txt and output.json or output.md.
Record exact source IDs, source file hashes where available, model/version when exposed,
configuration, human checks, discrepancies, and final resolution. Record unavailable
model details honestly. Model outputs may vary; preserve the actual output used.
Keep proposals here until a human verifies them. Declare AI use in the review methods.
Logs can contain excerpts or restricted data; share only permitted material.
